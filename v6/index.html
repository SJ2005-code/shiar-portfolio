THE FEATURE

Between a keyboard and a soldering iron.

Most engineers pick a lane. Shiar Haweez runs both: shipping software in the morning, soldering battery packs by afternoon, and automating whatever repeats.

I'm Shiar, a software and automation engineer from Erbil, and I've always lived between two worlds: a keyboard and a soldering iron. One week I'm writing C# against a SQL Server database, the next I'm assembling lithium battery packs or building a hydraulic press from raw parts.

"If something can be done in one command instead of ten, I've already scripted it."

I studied Information Technology at Khabat Technical Institute, where my graduation project was a full SQL Server database: complex queries, views, maintenance procedures, evaluated by real assessors. Before that I finished secondary school in Sweden, which is where my four working languages come from: Kurdish, English, Swedish, and Norwegian.

Right now I run operations and marketing at NORDO restaurant in Erbil. The launch, the branding, the Stripe payments, even the financial templates are mine. And in my spare hours? I train machine-learning pipelines on Kaggle data and automate everything I touch.
